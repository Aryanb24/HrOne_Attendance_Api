# Employee Attendance & Analytics API

A FastAPI and MongoDB backend service implementing employee attendance tracking, manual regularization with audit trails, and reporting analytics pipelines adhering to business rules R1–R10.

## Requirements
* Python 3.11+
* MongoDB 6.0+ (Local Docker or MongoDB Atlas)
